The first release of **Yapix**, a security-maintained continuation of [YApi](https://github.com/YMFE/yapi) 1.12. It runs on your existing YApi database.

### Highlights

- **Scripts are isolated.** Mock scripts and test assertions run in a separate V8 isolate with memory and time limits, not in vm2/safeify.
- **Tokens can't be forged.** Without `passsalt`, YApi encrypted project tokens with a public key. Yapix uses a random secret and refuses those tokens (`legacyTokens` for a migration period).
- **Safer defaults.** No `ymfe.org` admin password, scrypt password hashes, closed registration in the example config, TLS checks for server-side tests (CVE-2025-70058), no MongoDB operators in API parameters.
- **Current platform.** Node.js 24, Mongoose 9 with MongoDB 4.4–8, Koa 3, a client built with webpack 5. Known advisories in production dependencies: 244 → 1 (mitigated).
- **A browser extension that works again.** Yapix Request Helper (Manifest V3) replaces cross-request for the Run tab. It is attached below and served by Yapix itself.
- **Docker image** for amd64 and arm64: `ghcr.io/perruer/yapix:2.0.0`.

### Upgrading

Back up MongoDB and read [UPGRADING.md](https://github.com/Perruer/yapix/blob/main/UPGRADING.md): MongoDB 4.4+ is required, and project tokens made by YApi without `passsalt` must be replaced.

Full list of changes: [CHANGELOG.md](https://github.com/Perruer/yapix/blob/main/CHANGELOG.md).
